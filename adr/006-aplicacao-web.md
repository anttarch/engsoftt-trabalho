# Aplicação WEB

## Estado

Aceito

## Contexto

É necessário uma base de fácil acesso e de fácil desenvolvimento para o sistema, considerando as habilidades da equipe (estudantes) e a portabilidade necessária para a aplicação.

## Decisão

Construir o sistema utilizando com base a WEB, usufruindo das APIs e conexões.

## Consequências

Como aplicação WEB, o sistema é facilmente acessado de qualquer dispositivo que tenha um navegador e uma conexão com a internet, sendo assim, a acesibilidade é garantida. Entretanto, a compatibilidade com as plataformas (Desktop, Android e iOS) pode ser limitada por diferenças entre os navegadores.
