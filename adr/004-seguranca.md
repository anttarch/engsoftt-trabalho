# Segurança

## Estado

Aceita 

## Contexto

Como o Veridict é um sistema de ações burocráticas é necessário que os dados e a identidade do usuário sejam preservados, assim como a garantia de que é o próprio cliente que etá usando a aplicação e não uma invasão.

## Decisão

Para garantir que problemas relacionados a isso não ocorram é necessário garantir que a segurança esteja como uma da prioridades arquiteturais no desenvolvimento do sistema.

## Consequências

Algumas consequências e ações a serem tomadas tendo em vista essas características é a autentificação em duas etapas pelo email no momento de cadastro. Outro ponto importante é a recuperação de conta caso o usuário esqueça a senha, ela também será feita via email
