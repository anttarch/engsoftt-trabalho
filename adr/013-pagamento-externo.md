# Pagamento por serviço externo 
## Estado 
Aprovada

## Contexto 
Como o Veridt apresenta possibilidade de compra de créditos para as gravações e capturas, determina também que o pagamento é efetuado via qr code ou código pix copia e cola diretamente na aplicação web, é interessante a integração com outras APIs para pagamento.

## Decisão
Utilizaremos um checkout transparente com as informações aparecendo diretamente na interface do Veridt

## Consequências 
Necessidade de segurança maior.
